# FCMB Group Expansion Playbook

Interactive HTML playbook for FCMB Group’s African expansion operating system.

## Four pillars

1. **Stakeholder Management** — regulators, majority/minority shareholders, advisors, local expertise, vendors
2. **Selection Process** — country filters, greenfield vs brownfield, bank vs NBFI pathways
3. **Due Diligence** — quality benchmarks, workstream laundry lists, interactive go / no-go gate
4. **Integration & Transformation** — Bayport / Credit Direct 100-day roadmap and Day-100 KPIs

Plus a **peer benchmark** of seven African banks with the broadest expansion footprints.

## Local preview

Open `index.html` in a browser, or:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.
